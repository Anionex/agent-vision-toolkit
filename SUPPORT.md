# Support

## Start Here

- Read [README.md](README.md) for the toolkit overview and Quick Start.
- Follow [AGENT_INSTALL.md](AGENT_INSTALL.md) for host-specific seamless integration and troubleshooting.
- Check existing [issues](https://github.com/Anionex/agent-vision-toolkit/issues) and [pull requests](https://github.com/Anionex/agent-vision-toolkit/pulls) before opening a new report.

## Where to Ask

- Reproducible bug: use the bug report form.
- Setup or usage question: use the setup or usage question form.
- Focused improvement: use the feature request form.
- Security concern: follow [SECURITY.md](SECURITY.md) and report it privately.
- Code contribution: read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.

Open the repository's [issue chooser](https://github.com/Anionex/agent-vision-toolkit/issues/new/choose) to select the appropriate form.

## Information to Include

Provide the agent host, operating system, Python or Node version, affected component, minimal reproduction steps, expected behavior, and sanitized output. Remove API keys, Authorization headers, request bodies, prompts, conversations, and private image content.
