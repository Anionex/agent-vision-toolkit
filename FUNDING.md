# 赞助 / Funding

## 中文

agent-vision-toolkit 以 MIT License 开源。如果项目为你节省了时间，可以通过 [爱发电](https://ifdian.net/a/anionex) 支持持续开发。

一次性赞助或组织赞助可发送邮件到 `davidyang042@gmail.com`，标题注明 `agent-vision-toolkit sponsorship`。

赞助主要用于：

- 不同模型与服务商的视觉 API 实测；
- 跨平台、跨宿主验证；
- 测试样例、兼容性工作与长期维护；
- 文档与可复用的视觉 Agent 工作流。

赞助不会换取路线图控制权或安全例外。Bug、功能建议和代码贡献仍按项目公开流程处理。

非资金支持同样有帮助：Star 或分享仓库、提交可复现的问题、改进文档，以及贡献聚焦的测试或修复。

## English

agent-vision-toolkit is open source under the MIT License. If it saves you time, you can support its continued development through [Afdian](https://ifdian.net/a/anionex).

For one-time or organization sponsorship, contact `davidyang042@gmail.com` with the subject `agent-vision-toolkit sponsorship`.

Sponsorship is used for:

- vision API evaluations across models and providers;
- cross-platform and multi-host verification;
- test fixtures, compatibility work, and maintenance;
- documentation and reusable visual-agent playbooks.

Financial support does not purchase roadmap control or security exceptions. Bugs, feature proposals, and contributions continue to follow the same public project process.

Non-financial support also helps: star or share the repository, report reproducible bugs, improve documentation, or contribute focused tests and fixes.
