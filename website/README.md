# agent-vision-toolkit landing page

React + Vite landing page for the project. The visual system reuses the
blue-and-white palette and imagery from the repository's existing hero and
focus-hint explanation graphics.

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```

The production bundle is written to `dist/`.

## Main dependencies

- `lucide-react` for interface icons
- `chart.js` for the interactive tool-routing chart
- `gsap` for entrance, scroll, and ambient motion
